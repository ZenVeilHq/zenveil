# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Email **security@zenveil.dev** with:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact (what an attacker could do)
- Any proof-of-concept code (if applicable)

We will acknowledge your report within **48 hours** and keep you informed as we work on a fix.

## Scope

In scope:
- zenveil.dev (web app, API)
- Authentication and session handling
- Scan result data exposure
- Payment and billing logic

Out of scope:
- Denial of service attacks
- Social engineering
- Spam or phishing

## Disclosure Policy

We follow coordinated disclosure. Once a fix is deployed, we will:

1. Credit the researcher in our [CHANGELOG](./CHANGELOG.md) (unless you prefer to remain anonymous)
2. Publish a summary of the issue and fix

We do not currently offer a paid bug bounty program, but we deeply appreciate responsible disclosures and will acknowledge all valid reports publicly.
