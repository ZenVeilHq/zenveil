# Changelog

All notable changes to ZenVeil are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [Beta] — 2026-06

### Launched
- Public repository scanning via the homepage — no account required
- Authenticated scanning with higher rate limits (sign in with GitHub)
- Private repository scanning for Pro and Team plans
- Secret detection: API keys, tokens, passwords, private keys
- Dependency CVE scanning (npm, PyPI, Go modules)
- CI/CD pipeline risk analysis
- OWASP Top 10 pattern detection
- AI-powered remediation suggestions
- Stripe billing — Pro and Team plans
- Dashboard with scan history and finding details

Older changes are internal. Public changelog begins at beta launch.
