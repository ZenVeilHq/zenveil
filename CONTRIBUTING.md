# Contributing to ZenVeil

Thanks for your interest in contributing. The core ZenVeil platform is proprietary, but this repository — which contains community resources, examples, and documentation — welcomes contributions.

## What you can contribute

- **Documentation fixes** — typos, clarifications, better examples
- **Examples** — intentionally vulnerable apps, scan report samples
- **Guardrails** — Cursor rules, AI coding prompts, OWASP checklists
- **Translations** — help make security accessible in more languages

## How to contribute

1. Fork this repository
2. Create a branch: `git checkout -b fix/your-description`
3. Make your changes
4. Open a pull request with a clear description of what changed and why

## Standards

- Keep examples intentionally simple — the point is to illustrate a vulnerability, not build a full app
- Do not include real credentials, tokens, or personal data in any example
- Vulnerable examples must have a clear comment explaining the vulnerability and how to fix it
